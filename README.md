# Sales-Movie-Data-Analytics-Dashboard

Proyek visualisasi data menggunakan Looker Studio untuk menyajikan insight dari dua dataset berbeda, yaitu penjualan produk dan film IMDb Top 1000.

## 🛍️ Sales Dashboard: Analisis pendapatan, tren penjualan, kategori produk, produk terlaris, dan persebaran penjualan berdasarkan kota.

## 🎬 IMDb Dashboard: Analisis rating film, tren jumlah film per tahun, rating berdasarkan genre, dan film dengan rating tertinggi.

## Tools: Looker Studio, Data Visualization, Data Analytics
